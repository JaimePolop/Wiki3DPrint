Tests de impresora

Tests de impresora 3D: velocidad, color, flujo y calidad

No pruebes valores al azar. Cada test debe responder una pregunta concreta: cuánto plástico puede fundir tu hotend, qué velocidad aguanta la máquina, qué retracción necesita y cómo se comporta el color.

Ver testsVer cálculos

Orden recomendado de pruebas

Los tests tienen sentido si se hacen en orden. Primero elimina problemas de montaje y primera capa; después mide material, extrusión y dinámica. Si haces un test de velocidad con la boquilla atascada o el filamento húmedo, el resultado no sirve.

MecánicaPrimera capaMaterialFlujoDinámicaValidación

1. Base física

Correas, poleas, estructura, cama limpia, boquilla limpia, ventiladores y Z-offset. Sin esto, cualquier test da falsos positivos.

2. Perfil de material

Torre de temperatura, flujo, retracción y ventilación. Cada marca y color puede necesitar ajustes distintos.

3. Capacidad real

Velocidad máxima, flujo volumétrico, aceleración, resonancias, puentes y voladizos. Aquí descubres el límite de tu máquina.

4. Validación final

Cubo, tolerancias, test de color y Benchy. Sirven para confirmar que el perfil funciona en piezas reales.

Biblioteca de tests principales

Esta es la parte práctica. Cada tarjeta indica qué modelo imprimir, qué problema aísla, cómo hacerlo y cómo tomar la decisión. No cambies cinco parámetros a la vez: imprime, mide, cambia una cosa y repite.

BASE

Test de primera capa

Modelo: cuadrado grande de una capa o patrón de malla del slicer.

Para qué sirve: comprobar Z-offset, nivelación, limpieza de cama y adhesión.

Cómo hacerlo: imprime una sola capa lenta. Debe quedar continua, sin huecos y sin surcos excesivos.

Lectura: líneas separadas = boquilla alta. Superficie arañada o transparente = boquilla baja.

MATERIAL

Torre de temperatura

Modelo: torre de temperatura de OrcaSlicer, Teaching Tech o modelo STL con cambios por altura.

Para qué sirve: encontrar la temperatura con buena unión de capas, detalle, puentes y poco stringing.

Cómo hacerlo: imprime tramos de 5 °C o 10 °C. Para PLA suele tener sentido probar entre 190 y 220 °C.

Lectura: elige el tramo con mejor equilibrio, no solo el más bonito. Si las capas parten fácil, falta temperatura.

HILOS

Test de retracción

Modelo: dos o más torres finas separadas.

Para qué sirve: reducir hilos en movimientos en vacío sin provocar atascos o huecos.

Cómo hacerlo: fija primero la temperatura. Después prueba distancia y velocidad de retracción en pasos pequeños.

Lectura: pocos hilos sin clics del extrusor, sin marcas profundas y sin huecos al reiniciar la línea.

Abrir modelo/generador

FLUJO

Test de flujo o extrusion multiplier

Modelo: pared simple, placa de flujo o calibración integrada del slicer.

Para qué sirve: ajustar cuánto material deposita realmente la impresora.

Cómo hacerlo: imprime un patrón de flujo después de calibrar temperatura. Mide paredes o compara superficies superiores.

Cálculo: nuevo flujo = flujo actual x medida objetivo / medida real. Si esperas 0,45 mm y mides 0,48: 100 x 0,45 / 0,48 = 93,75%.

DIMENSIONES

Cubo XYZ

Modelo: cubo de 20 mm con letras X, Y y Z.

Para qué sirve: comprobar dimensiones, esquinas, ringing, elephant foot y regularidad de capas.

Cómo hacerlo: imprime con el perfil que quieres validar y mide cada eje con calibre sin apretar la pieza.

Lectura: X/Y grandes suele ser flujo o expansión horizontal. Z raro apunta a primera capa, altura de capa o eje Z.

Abrir modelo 3D

RAPIDEZ

Test de velocidad y flujo volumétrico

Modelo: speed tower, max flow test o torre de flujo volumétrico.

Para qué sirve: saber la velocidad máxima real antes de subextruir.

Cómo hacerlo: sube velocidad por tramos y observa cuándo aparecen líneas finas, capas débiles, clics o pérdida de brillo.

Cálculo: flujo volumétrico = ancho de línea x altura de capa x velocidad. Ejemplo: 0,45 x 0,20 x 120 = 10,8 mm³/s.

Abrir modelo/generador

DINÁMICA

Test de aceleración, ringing e input shaping

Modelo: ringing tower, acceleration tower o prueba de resonancias de Klipper.

Para qué sirve: encontrar aceleraciones rápidas sin ondas alrededor de esquinas ni desplazamientos de capa.

Cómo hacerlo: imprime una torre subiendo aceleración por alturas. En Klipper, input shaping puede medirse con acelerómetro o test manual.

Lectura: usa la aceleración más alta que no deje ecos visibles, vibraciones fuertes ni layer shifting.

Abrir modelo/generador

ESQUINAS

Pressure advance / linear advance

Modelo: patrón de líneas, torre PA o calibración del slicer/firmware.

Para qué sirve: compensar la presión interna del hotend en esquinas, frenadas y arranques.

Cómo hacerlo: imprime valores progresivos y compara esquinas. Deben quedar cerradas, sin bultos y sin huecos.

Lectura: valor bajo = esquinas gordas. Valor alto = huecos o esquinas débiles.

Abrir modelo/generador

REFRIGERACIÓN

Test de puentes y voladizos

Modelo: bridge test y overhang test de 40 a 75 grados.

Para qué sirve: comprobar ventilador de capa, temperatura, velocidad de puente y orientación de pieza.

Cómo hacerlo: imprime con el perfil real. No uses soportes; el objetivo es ver hasta dónde llega la máquina sola.

Lectura: puentes caídos = demasiado calor, poca ventilación o puente muy rápido. Voladizos rugosos = falta refrigeración o demasiada velocidad.

DISEÑO

Test de tolerancias y encajes

Modelo: clearance test, agujeros calibrados, tuercas cautivas o piezas print-in-place.

Para qué sirve: saber qué holgura necesitas para bisagras, ejes, tapas, tornillos e inserts.

Cómo hacerlo: imprime una pieza con holguras de 0,1 a 0,5 mm y prueba qué parte se mueve sin fuerza.

Lectura: si 0,2 mm no se mueve y 0,3 mm sí, diseña tus piezas funcionales con al menos 0,3 mm de holgura.

Abrir modelo 3D

COLOR

Test de color, cambio de filamento y multimaterial

Modelo: placa con franjas de color, logo en dos colores, purge tower o modelo pequeño con cambios por capa.

Para qué sirve: comprobar contaminación entre colores, purga, alineación, costura y cambios de material.

Cómo hacerlo: imprime colores claros después de oscuros para ver contaminación. Ajusta purga en el slicer o el volumen de flush de AMS/MMU.

Lectura: si el blanco sale gris, falta purga. Si la torre desperdicia mucho y el color sale limpio, puedes bajar purga poco a poco.

Abrir calibraciones

VALIDACIÓN

Benchy y pieza de control

Modelo: 3DBenchy y una pieza real que tú uses a menudo.

Para qué sirve: confirmar primera capa, paredes, puentes, chimenea, curvas, refrigeración y dimensiones en una sola pieza.

Cómo hacerlo: imprime después de los tests principales, no antes. Benchy es una validación, no una respuesta mágica.

Lectura: base mala = cama/Z. Hilos = temperatura/retracción. Ondas = aceleración. Puentes caídos = refrigeración.

Cálculos útiles para tests

Los tests de rapidez y calidad no se interpretan solo mirando la pieza. Estos cálculos te ayudan a saber si el límite viene del hotend, del movimiento, del material o del perfil.

CálculoFórmulaEjemploPara qué sirve
Flujo volumétricoancho de línea x altura de capa x velocidad0,45 x 0,20 x 120 = 10,8 mm³/sSaber si el hotend puede fundir suficiente plástico.
Velocidad máxima por flujoflujo máximo / (ancho x altura)12 / (0,45 x 0,20) = 133 mm/sNo pedir más velocidad de la que el hotend puede alimentar.
Corrección de flujoflujo actual x medida objetivo / medida real100 x 0,45 / 0,48 = 93,75%Ajustar extrusion multiplier cuando las paredes salen gruesas o finas.
Error dimensionalmedida real - medida objetivo20,18 - 20 = +0,18 mmSeparar error de flujo, contracción, expansión horizontal o mecánica.
Holgura mínimaprimer hueco que se mueve libre0,3 mm funciona, 0,2 mm noDiseñar encajes, bisagras y piezas print-in-place.
Purga de colorsubir/bajar volumen por contaminación visible+10% si queda color anterior; -5% si sobra torre limpiaOptimizar cambios de color sin tirar material de más.
Regla práctica

Si al subir velocidad aparecen líneas finas pero la mecánica no vibra, probablemente el límite es flujo volumétrico. Si aparecen ondas, ecos o capas desplazadas, el límite es dinámica.
