Materiales de impresión 3D

Aquí tienes una página específica para cada material base importante y para varios derivados habituales. La idea es que no tengas una ficha de dos líneas, sino una biblioteca útil para decidir, imprimir y diagnosticar mejor.

Cómo leer cada ficha

  • Empieza por “cuándo tiene sentido” para no usar un material técnico sin motivo.
  • Revisa secado, dificultad y defectos comunes antes de tocar el slicer.
  • Mira la nota para `Bambu A1` si vienes de una impresora de entrada moderna.
  • Usa la biblioteca como sistema de decisión, no como lista decorativa de filamentos.
